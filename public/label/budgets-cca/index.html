04la tva — apport ttc, coût net plus bas

arch est une sas assujettie : la tva sur les factures fournisseurs (prod + promo) est récupérable. l'avance, elle, est un salaire sans tva. donc le cca doit apporter le ttc en trésorerie pour décaisser, mais une partie revient via la déclaration de tva.
